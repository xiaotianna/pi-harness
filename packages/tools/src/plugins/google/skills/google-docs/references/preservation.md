# Preservation and delivery

Record the source URL/ID, requested sections/tabs/slides and the exact user-directed changes. Keep structure separate from factual content: a past example can guide layout without making its dates, owners or results current. Preserve required native elements when they are observable and editable; disclose any unavailable read/write or fidelity prerequisite.

For an existing file, read the affected content before preparing replacements and retain unaffected material. Distinguish proposed text, proposed properties and verified source facts. Cite exact passages or known tab/range/slide locations; never fabricate native object IDs or URLs.

For a local output, choose Markdown, DOCX, XLSX or PPTX according to the request and use the corresponding local document workflow when available. Verify actual text/data and render where layout matters. A local artifact is not a cloud edit, and a text export is not proof of preserved tabs, chips, formulas or layout. For a requested cloud mutation, complete the concrete proposal first and state the missing native write surface.
