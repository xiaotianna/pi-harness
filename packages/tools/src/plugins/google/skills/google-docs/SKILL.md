# Google 文档

The gateway base is `{skillGatewayUrl}/api/skill-gateway/google`. Read [access and coverage](references/access.md) before choosing a retrieval or output route.

## Workflow

Determine whether the supplied document is a current source, a reusable template or a past example. Preserve the requested structure without carrying stale people, dates, metrics or approvals into new content. Text export is suitable for reading prose but does not expose complete tab topology, styles, smart chips, dropdowns or native controls. For an edit requiring these, request a native-capable surface or a supplied structured export and prepare the proposed text meanwhile. Do not represent a DOCX reconstruction as a faithful native copy of a multi-tab template. For new local drafts use the documents Skill when enabled and verify the resulting file; deliver it as a local artifact, not a published Google Doc.

Read [preservation and delivery](references/preservation.md) for editing and template requests. Use the supplied facts and current project instructions; ask only for information that materially blocks the requested task.
