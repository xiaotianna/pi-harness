# Google 幻灯片

The gateway base is `{skillGatewayUrl}/api/skill-gateway/google`. Read [access and coverage](references/access.md) before choosing a retrieval or output route.

## Workflow

Identify the presentation, source facts, requested slide scope and template role. Text export can support an outline or prose review but cannot verify slide geometry, mixed text styles, charts, notes, links or image cropping. For visual/template work use a supplied PPTX/PDF or an available native read/render surface. Preserve the layout families and editable text of an actual template; do not create a blank reconstruction and describe it as a native copy. Use the presentations Skill for a requested local PPTX draft when enabled. Verify each affected slide visually when a render is available and distinguish text-only review from visual QA.

Read [preservation and delivery](references/preservation.md) for editing and template requests. Use the supplied facts and current project instructions; ask only for information that materially blocks the requested task.
