# Search and evidence coverage

Start with the supplied page when available. Otherwise search a small set of title terms via the access guide, deduplicate results by page ID, then read the most relevant properties and blocks. Search only covers content shared with the integration; a missing result does not prove a page does not exist.

Use returned metadata to compare freshness and authority. Read the actual supporting passage before citing a page. For a known page hierarchy, traverse relevant child pages/blocks with bounded pagination. For known data sources inspect schema and available rows, then report partial coverage if the query is paginated beyond current gateway support.

Do not use teamspace/creator/date search filters or connected Slack/Drive searches that the gateway does not expose. For time comparisons, use dates on retrieved records and distinguish publication, last edit and event time. If titles are ambiguous, narrow using the available context or ask which source is intended.

Record title, URL, page ID, retrieved scope, source date and claim supported. Group related findings, surface contradictions and prefer primary records over repeated summaries. Refine sparse results with alternate title wording rather than repeatedly issuing the same failed request.
