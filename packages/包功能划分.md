| 子包            | 作用                                                                                                                |
| --------------- | ------------------------------------------------------------------------------------------------------------------- |
| `agent-runtime` | 核心编排层。创建和管理 Agent、恢复上下文、控制一次只能有一个活动 run，并把 Pi 原始事件转换成 `WorkbenchEvent`。     |
| `providers`     | 模型与凭据层。按需注册 OpenAI、Anthropic 等 Provider，管理模型列表和 API 凭据；凭据不能暴露给 Web。                 |
| `tools`         | Agent 的本地操作能力。计划提供 `read_file`、`list_files`、`search_text`、`edit_file`、`write_file`、`run_command`。 |
| `policy`        | 安全和审批层。负责路径边界检查、命令策略，以及写文件或运行命令前的用户审批。                                        |
