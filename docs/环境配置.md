# 环境配置

真实配置保存在本机 `.env`，加密副本 `.env.enc` 可以提交到仓库。

```bash
pnpm env:encrypt
pnpm env:check
```

首次加密会生成随机密钥并保存到 Mac 钥匙串。运行 `pnpm env:key:copy`，将复制出的恢复密钥保存到密码管理器。

换机后先从密码管理器取回密钥，再执行：

```bash
PI_HARNESS_ENV_ENCRYPTION_KEY=<恢复密钥> pnpm env:key:store
pnpm env:decrypt
```

修改 `.env` 后重新运行 `pnpm env:encrypt`，再提交更新后的 `.env.enc`。
